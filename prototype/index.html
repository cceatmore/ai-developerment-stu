P0为什么不能把所有文档直接塞进 Prompt？

一句话记住：上下文窗口装得下，不等于模型用得好；RAG 的本质是“只把相关的证据交给模型”。

1. 它解决什么问题

模型的知识停在训练截止日，也不知道企业内部文档。RAG 在每次提问时，先从知识库找到相关片段，再让模型基于这些片段回答。

3. 常见误区

  • “窗口 128K 就能全塞”：成本、延迟随 Token 线性增长；长上下文中段信息容易被忽略。
  • “相似度高 = 答案对”：相似只说明语义接近，不说明片段包含答案。

4. 面试官可能这样问

“你们的知识库为什么用 RAG 而不是微调？”
